
# Network Troubleshooting Labs

A collection of hands-on enterprise networking labs, troubleshooting scenarios, and technical documentation developed using EVE-NG and Cisco virtual devices.

This repository showcases my practical learning journey in network engineering, focusing on network configuration, monitoring, troubleshooting, and infrastructure operations.

## About Me

I am an aspiring Network Engineer working towards developing strong technical skills in enterprise networking and network operations.

I use virtual lab environments to implement networking technologies, investigate connectivity issues, identify root causes, and document troubleshooting procedures.

My focus is on building practical knowledge that can be applied to real-world network operations and infrastructure environments.

## Troubleshooting Methodology

Each project follows a structured troubleshooting approach:

1. Problem identification and symptom analysis
2. Network topology and configuration review
3. Information gathering and initial investigation
4. Troubleshooting using appropriate CLI commands and tools
5. Root cause identification
6. Corrective action and configuration
7. Verification and connectivity testing
8. Documentation and lessons learned

## Lab Environment

All projects are independently developed in a virtual lab environment using EVE-NG and Cisco virtual devices.

Configurations, command outputs, topology diagrams, and test results are documented wherever applicable.
